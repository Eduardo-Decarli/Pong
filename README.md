# 🕹️ Pong - Jogo Clássico em JavaScript

Bem-vindo ao repositório do **Pong**, uma recriação do clássico jogo de tênis de mesa utilizando **HTML5 Canvas** e **JavaScript puro**.

---

## 🎯 Objetivo

O objetivo do jogo é simples: impedir que a bola passe pela sua raquete e marcar pontos quando o adversário falhar.

---

## 🧠 Funcionalidades

- Renderização gráfica com `canvas`
- Controle do jogador com teclado (setas ↑ ↓)
- Movimento automático da IA (bot)
- Sistema de colisão com bordas e raquetes
- Contagem de pontos e reinício da bola
- FPS ajustável

---

## 💻 Tecnologias utilizadas

- HTML5
- JavaScript (ES6)
- Canvas API

---

## ▶️ Como rodar o jogo

1. Clone o repositório:

```bash
git clone https://github.com/Eduardo-Decarli/Pong.git
```

2. Abra o arquivo index.html no seu navegador.

Não é necessário servidor ou instalação.
